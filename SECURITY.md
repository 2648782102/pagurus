# Security policy

Please do not publish credentials, private user data, or an unpatched vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository when enabled, or contact the maintainers through the account profile.

Pagurus is early software. Configuration writes are limited to Conchbase `0.5.0`'s published validate/apply routes; they store bounded opaque references and v2 composition data, not secrets or executable capabilities. Use only with a local Conchbase runtime until authenticated pairing is designed.
